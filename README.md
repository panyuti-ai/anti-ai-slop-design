# anti-ai-slop-design

A Claude skill: a workflow and prompting rules for getting non-generic UI, slide, and motion design from Claude.

## Install

Copy `SKILL.md` into a folder named `anti-ai-slop-design` inside your skills directory, for example `~/.claude/skills/anti-ai-slop-design/SKILL.md`.

## What it covers

- Diverge-then-converge option rounds
- Wireframes first for hard layouts
- Recreating designs from an existing codebase
- Prompt rules that block Claude's default look
- Feedback style, comments, and clarifying questions
- Motion pacing, dashboards, and evaluation
